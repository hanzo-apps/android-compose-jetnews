# android-compose-jetnews

News reader in Jetpack Compose — adaptive list/detail, Glance widget, dark theme.

**Lane:** Jetpack Compose · **Live demo:** https://android-compose-jetnews.hanzo.app

## Run it on Android

```sh
./gradlew installDebug
```

## Provenance

Forked from [android/compose-samples](https://github.com/android/compose-samples) — `JetNews`, licensed **Apache-2.0**.
The upstream `LICENSE` is kept verbatim in this repo; the copyright stays with
its authors. Changes made here are limited to what a standalone fork needs
(see the initial commit).

## Preview

Jetpack Compose has no web target, so https://android-compose-jetnews.hanzo.app is a
**screenshot gallery**, not a running app: the upstream's own Apache-2.0
screenshots, labelled as such. Build the APK with `./gradlew assembleDebug` —
our CI cannot do it for you yet (see the fleet note in the initial commit).
